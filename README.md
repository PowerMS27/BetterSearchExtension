## Description

A browser extension that provides an alternative search bar available on all web pages. It can be opened with **Ctrl&nbsp;+&nbsp;Shift&nbsp;+&nbsp;F&nbsp;** (instead&nbsp;of&nbsp;**Ctrl&nbsp;+&nbsp;F**). The extension includes an input field for entering search text and a toggle that enables or disables automatic result updates when page content changes.

When enabled, search results automatically refresh whenever the website content changes - for example, when navigating through pagination or opening menus. The toggle's state is saved per website, so when you revisit the same site, Better Search remembers your previous setting.

A CI/CD pipeline with automated unit tests is implemented to ensure the search functionality works correctly across all scenarios.
